Sudoku Web Game

Status: Selesai Dikerjakan: Agustus 2026

Penjelasan Projek

Proyek ini adalah sebuah permainan Sudoku interaktif berbasis web. Tujuan dari proyek ini adalah untuk menerapkan logika pemrograman JavaScript ke dalam antarmuka web. Pemain dapat mengisi angka, memvalidasi jawaban, dan menyelesaikan teka-teki Sudoku dengan antarmuka yang bersih dan responsif.


Teknologi yang digunakan

  • HTML5 untuk struktur halaman
  • CSS3 untuk styling dan layout responsif
  • JavaScript untuk logika permainan dan interaktivitas
