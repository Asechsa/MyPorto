Prediksi Churn Pelanggan

Status: Selesai Dikerjakan: Agustus 2026

Penjelasan Projek

Proyek machine learning ini bertujuan untuk memprediksi probabilitas seorang pelanggan untuk berhenti menggunakan layanan (churn) berdasarkan data historis. Dengan model ini, bisnis dapat melakukan intervensi dini untuk mempertahankan pelanggan mereka.


Teknologi yang digunakan:

  • Python untuk bahasa pemrograman utama
  • Pandas untuk manipulasi dan analisis data
  • Scikit-learn untuk pembuatan dan evaluasi model Machine Learning
  • Google Colab sebagai environment pengembangan
